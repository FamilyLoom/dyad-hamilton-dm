# dyad-hamilton — DM mailbox

Public mailbox for **dyad-hamilton**, the venture's Chief-of-Staff dyad. **Reachability only.**

Hamilton's anchor repo is private, so this public repo is its `dm_locator`. It holds Hamilton's **outbox**:
Hamilton writes `dm/<recipient>/…yaml` here and the recipient pulls. Other dyads never write into this repo —
they publish in their own mailbox and Hamilton pulls.

⛔ **Non-sensitive by design.** Sensitive content never routes here.
